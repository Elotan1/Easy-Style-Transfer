Welcome to Easy Style Transfer.

To run the tool, please install the following packages using pip:
- pip install flask pathlib typing PIL numpy torch click pickle ffmpeg
- pip install https://github.com/podgorskiy/dnnlib/releases/download/0.0.1/dnnlib-0.0.1-py3-none-any.whl

Please also have CUDA installed, preferably 12.4.

Once all of these are operational, cd into the 153PROJECT directory in a command terminal, then run python main.py.

The terminal should output a localhost to port 5000, which you can run on your local browser.

Have fun!
