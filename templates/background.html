Background

Motivation:

Style transfer has existed for almost a decade yet is still difficult to access if you lack the proper computing power to train new datasets. Many people only have access to basic CPUs, but efficient GPUs may be necessary to even train a large set of data. Our project aims to provide users with a tool that has sufficient ease of use while still being a robust way to explore and create different styles. The tool will act to transfer a multitude of artistic styles to images generated in real time by users, so that they can easily create their own unique aesthetic from any device! Aspiring creators can use this tool to experiment with style transfer onto generated images and adjust them as they see fit.

Approach:

We will create this tool by using StyleGan2, a style transfer learning repository, to train off a dataset consisting of a variety of different style classes. StyleGan2 relies on a generative adversarial network to train the model, which also serves to be able to mimic the style classes to create new outputs. Using this trained adversarial network, we plan to produce a tool that can allow a user to experience style transfer on our pretrained network. By training the model beforehand, we will have access to multiple styles and be able to provide a default set of styles that the user can interact with.

Verification Process:

To gauge the success of our tool, we will be using our own visual acuity, as well as the existing adversarial model. We then created this UI with html and CSS with an established backend (FLASK) to run Python for an easy interfacing with the tool.
