Method

StyleGan2:

To train our data, we used StyleGan2. The model is trained using a generative adversarial network, which tries to trick the model repeatedly through falsely generated images. Using a provided loss function, the model can learn its accuracy every iteration of the training (tick) to better learn how to classify the data.

WikiArt:

Our dataset was acquired from hugging face's wikiart dataset. The dataset consists of:

  • 129 artist classes
  • 11 genre classes
  • 27 syle classes

Using StyleGan2, we trained wikiart to classify the styles. Since every image needed to have the same dimensions, we cropped and resized the entire dataset to 256x256 RGB images.

This is a partition of the original dataset images. The discriminator model will try to differentiate these images under classes of style.

The generative adversarial network initializes a set of fake images to try to trick the model


Overtime, the adversarial network becomes more efficient at generating fake images, which, with the help of the loss function, prompts the discriminator model to become better at classification.
